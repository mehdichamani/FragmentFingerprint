# Fragment Fingerprint (پروکسی و دور زدن فیلترینگ با قطعه‌بندی پکت‌ها)

این پروژه یک راه‌حل میانی (Local MitM Proxy / Relay) بر پایه هسته **Xray-core** (نسخه `26.7.28` و بالاتر) است که برای **دور زدن سیستم فیلترینگ هوشمند و DPI (Deep Packet Inspection)** از طریق تکنیک‌های پیشرفته **Fragment (قطعه‌بندی پکت‌های TCP / TLS Hello)** و بازسازی ساختار TLS به همراه پین کردن اثر انگشت گواهی (**Certificate SHA-256 Pinning**) طراحی شده است.

---

## 🎯 هدف پروژه و نحوه کارکرد

سیستم‌های فیلترینگ و DPI پکت‌های TLS Client Hello را برای شناسایی دامنه‌ها و پروتکل‌ها (مثل VLESS / Trojan / Shadowsocks روی TLS) اسکن و مسدود می‌کنند.

این پروژه یک پروکسی محلی/شبکه‌ای راه‌اندازی می‌کند که ترافیک کلاینت شما را دریافت کرده، گواهی امن پین‌شده ایجاد می‌کند و سپس بسته‌های خروجی به سمت سرور نهایی را به‌صورت تکه‌تکه (Fragment) با طول و تأخیرهای معین و رمزنگاری سفارشی ارسال می‌کند تا فیلترچی و فایروال قادر به تشخیص و مسدودسازی آن نباشند.

```
[ کلاینت (v2rayN / Sing-box / Nekoray / ...) ]
                   │
                   ▼ (TLS پین‌شده با SHA256 به 127.0.0.1:40443)
       [ هسته Xray این پروژه ]
                   │
                   ▼ (تکنیک Fragment + تغییر Cipher/ALPN به سمت مقصد اصلی)
[ سرور نهایی / CDN / آی‌پی سرور فیلترشده (مثلاً 188.114.97.6:443) ]
```

---

## 📦 محتویات و ساختار پروژه

- **`config.json`**: کانفیگ اصلی Xray شامل تنظیمات اینباند (`40443`)، گواهی‌های TLS و قوانین فرگمنت (`tlshello`, `packets`, `cipherSuites`).
- **`menu.bat` / `menu.ps1`**: منوی متنی و گرافیکی تعاملی تحت پاورشل (TUI) جهت مدیریت آسان، دانلود آخرین نسخه Xray، اجرای در پس‌زمینه و افزودن به تسک استارتاپ ویندوز.
- **`compose.yml`**: استقرار سریع از طریق داکر (Docker Compose) برای لینوکس، سرورها یا سیستم‌های مختلف.
- **`run_hidden.vbs`**: اجرای کاملاً مخفیانه و بدون باز شدن پنجره ترمینال در ویندوز.
- **`STARTUP_HELP.md`**: راهنمای تخصصی اجرای خودکار در پس‌زمینه در هنگام ورود به ویندوز.

## 🚀 راهنمای راه‌اندازی و استفاده

### گام ۱: تنظیم آدرس سرور نهایی (Target Address)

فایل `config.json` را باز کنید و در بخش `outbounds -> settings -> redirect` آدرس و پورت سرور/آی‌پی مورد نظر خود را قرار دهید:

```json
"settings": {
  "redirect": "188.114.97.6:443" // *** آدرس آی‌پی یا دامنه و پورت مقصد
}
```

---

### گام ۲: اجرای سرویس

#### روش اول: استفاده از منوی ویندوز (توصیه‌شده)
روی فایل `menu.bat` دبل‌کلیک کنید تا منوی مدیریتی باز شود:
- **گزینه `[1]`**: اجرای مستقیم Xray در ترمینال.
- **گزینه `[2]`**: افزودن سرویس به Task Scheduler جهت اجرای خودکار و مخفی در استارتاپ ویندوز.
- **گزینه `[4]`**: دانلود یا به‌روزرسانی خودکار آخرین نسخه هسته Xray-core از گیت‌هاب.
- **گزینه `[5]`**: بستن تمام پروسه‌های در حال اجرای Xray.

#### روش دوم: اجرا با داکر (Docker Compose)
در سیستم‌های لینوکسی یا سرور:
```bash
docker compose up -d
```

---

### گام ۳: تنظیم کلاینت (v2rayN / V2Box / Nekoray / Hiddify و ...)

در کلاینت خود، کانفیگ TLS خود را ویرایش کرده و مشخصات زیر را تنظیم کنید:

- **Address (آدرس سرور):** `127.0.0.1` (یا اگر برای کل شبکه LAN استفاده می‌کنید، IP لوکال سیستم)
- **Port (پورت):** `40443`
- **SNI / ServerName:** دامنه اصلی یا مطابق کانفیگ شما
- **Pinned Peer Certificate SHA-256 (اثر انگشت گواهی):**
  ```text
  3de5b7bd48c18c9ff057d8961f24c16555a7e387ebb509e1efb1315303695c82
  ```
